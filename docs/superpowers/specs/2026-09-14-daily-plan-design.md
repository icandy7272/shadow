# 首页日课卡片 + 完整日课页

## 要解决的问题

日课（每天怎么练、为什么这样排）以前是一个单独的 Artifact 页面，和 Shadow 分开放：

- 手机上要先登录 claude.ai 才能看。
- 内容不会跟着 Shadow 更新，里面还写着早就改成默写的「填空」。
- 看日课和练习是两件事，看完不知道今天练到哪一步了。

## 做什么

### 首页卡片「今天的日课」

放在素材标题下面、打卡格子上面，可以收起，收起状态记在本机浏览器里。

- 标题：`今天的日课 · 周一 · 30 分钟`。周六是 `回顾`，周日是 `轻松一天`。
- 进度行：`今天练了 2 句 · 连续 6 天`，数据来自打卡格子已经在算的数。
- 每一步是一个勾选框、一句说明，能跳转的带一个链接。勾选状态按「本地日期 + 步骤」存进数据库，手机和电脑看到的一样，第二天自动清空。
- 全部勾完，标题后面显示「做完了」。
- 底部链接「为什么这样排、时间不够时 → 完整日课」。

按星期排的步骤：

| 星期 | 步骤 | 链接 |
|---|---|---|
| 一至五 | 复习昨天：3–5 句，先盲听，跟不上的完整跟读一遍 | 筛出「该复习」的 N 句 |
| | 精练新句子：3–5 句，盲听 → 默写 → 看字跟读 → 不看字跟读 | 开始下一句（第 N 句） |
| | 串起来：今天练过的几句连着跟 2 遍，不停下来改 | — |
| | 复述：合上材料，用自己的话讲一遍，录下来回听 | — |
| | 泛听：碎片时间 10–20 分钟，原速，听懂大意就行 | — |
| 六 | 重练：本周没听懂、问题没解决的句子 | 筛出「该复习」的 N 句 |
| | 整段跟读：本周练过的句子从头跟到尾，不中断 | — |
| | 自由说：挑本周 3–5 个表达，就一个话题连着说 2 分钟，录音和上周对比 | — |
| | 泛听 | — |
| 日 | 复习 5 分钟，保住连续天数 | 筛出「该复习」的 N 句 |
| | 泛听或休息 | — |

没有要复习的句子时，链接换成「没有要复习的」；没有没练过的句子时，换成「这份素材练完了，去素材库换一份」。

### 句子列表加筛选「该复习」

- 规则：今天之前练过，并且满足以下任一条件：
  - 最后一次练是昨天；
  - 上次还有反复出现的问题；
  - 盲听自评不超过 2 分。
- 每行由服务端算好后带上 `data-review`，前端只做过滤。
- 卡片上的链接会点中这个筛选，并滚到列表。

### 完整日课页 `/plan`

- 把 Artifact 的内容搬进 Shadow 的模板，用 Shadow 自己的样式和系统字体，不加载网络字体。
- 按现状改掉过时的说法：「填空」改成「默写」，「Shadow 还缺的两样」去掉「素材库做完之后」那句。
- 从首页卡片进入，顶栏不再加入口（手机上顶栏放不下）。

### 顺手修

句子列表每一行多出一个空的「空」列单元格，表头已经删掉了。手机上按列序号隐藏列会因此错位。

## 数据

```sql
-- 日课勾选：哪天、哪一步。第二天自然就是新的一行
CREATE TABLE IF NOT EXISTS plan_checks (
    day        TEXT NOT NULL,      -- 本地日期 YYYY-MM-DD
    step       TEXT NOT NULL,
    checked_at TEXT NOT NULL,
    PRIMARY KEY (day, step)
);
```

- `db.plan_checks(conn, day) -> set[str]`
- `db.set_plan_check(conn, day, step, done: bool)`

## 代码

- `src/shadow/plan.py`：纯函数，不碰数据库。
  - `Step(key, title, detail, link)`，`link` 取值 `review`、`next` 或 `None`。
  - `steps_for(weekday: int) -> tuple[Step, ...]`
  - `heading(weekday) -> str`
  - `is_step(weekday, key) -> bool`：这一步今天有没有。
  - `needs_review(last_day, today, *, issues, rating) -> bool`：「该复习」的判断。
- `web/app.py`：
  - 首页上下文加 `plan`（标题、步骤、已勾、该复习几句），每行加 `review`。
  - 新增接口 `POST /api/plan {step, done}`：不认识的步骤返回 400；返回 `{step, done, all_done}`。
  - 新增页面 `GET /plan`。
- `templates/index.html`：卡片，删掉多余的单元格，加筛选按钮「该复习」。
- `templates/plan.html`：完整日课。
- `static/app.js`：
  - 勾选时调接口，失败就退回原状态并提示。
  - 卡片链接点中「该复习」筛选。
  - 记住卡片是否收起。
- `static/app.css`：卡片样式。

## 测试

- `tests/test_plan.py`：
  - 工作日、周六、周日各自的步骤。
  - 步骤的 key 在同一天里不重复。
  - `is_step` 能识别有效和无效的步骤。
- `tests/test_db.py`：勾选、取消、按天隔开。
- `tests/test_web_plan.py`：
  - 首页有卡片，标题带星期，有进度行和完整日课链接。
  - 勾选接口会存下来、刷新后还在；不认识的步骤返回 400；全部勾完时 `all_done` 为 true。
  - 「该复习」的判断：昨天练过、有反复出现的问题、自评低分会进；今天才练、从没练过的不进。
  - `/plan` 能打开，里面没有「填空」。
  - 表头和每一行的单元格数一样多。
