# 素材库：导入、切换、删除

日期：2026-09-12
状态：已确认，开始实现

## 背景

现在只能在命令行跑 `shadow import <url>` 导入素材。所有素材的句子排成一条列表，网页上不能切换，也不能删除。
导入第二份素材后，它的句子接在第一份后面，「开始下一句」会先推第一份没练完的句子。

## 目标

- 网页上贴链接导入，后台跑，页面上看进度
- 素材彼此分开，首页只显示当前这一份
- 在素材库里切换、删除。删除要彻底删掉素材、句子、练习记录和录音，只保留每日计数、打卡格子和连续天数

## 不做

- 上传本地音视频文件
- 同时导入多份
- 删除后恢复
- 修改素材标题

## 用户看到的

### 入口

- 每个页面的顶栏，「Shadow」旁边有「素材库」按钮
- 练习页顶上的素材名可以点，回到这份素材的句子列表
- 素材列表页的标题是素材名

### 首页 `/`

- 跳到当前素材的列表页 `/sources/{id}`
- 一份能练的素材都没有：跳到素材库 `/sources`

### 素材列表页 `/sources/{id}`

- 内容是现在首页的全部内容：打卡格子、筛选、句子表、「开始下一句」。句子、筛选和「开始下一句」只针对这一份
- 标题是素材名，副标题是「练过 X / Y 句 · N 分钟」
- 打开这个页面，就把它设为当前素材
- 打卡格子和连续天数统计全部素材，包括已删除素材的归档

### 素材库 `/sources`

- 顶部是链接输入框和「导入」按钮。有导入在跑时，按钮旁说明「上一份还在导入」
- 每份素材一张卡片：标题（还没查到标题时显示链接）、时长、练过 X / Y 句、最近一次练习时间
- 卡片状态：
  - 能练：当前那份标「正在练」，其余有「切到这份」；都有「删除」
  - 导入中：显示进行到哪一步（查信息 / 下载 / 转写 / 切句），不给删
  - 失败：显示原因，有「重试」和「删除」
- 有导入在跑时，每 2 秒刷新一次
- 导入完成不自动切换，卡片上出现「开始练」

### 删除

- 先弹确认，写明句子数、练习轮数、录音遍数，说明不能恢复、打卡保留
- 删的是当前素材：当前素材换成最近练过的另一份；没有别的能练的素材，就回到素材库

### 练习页

- 「第 N 句 / 共 M 句」和上一句、下一句，只在同一份素材里算

## 数据

### 新表

- `settings(key TEXT PRIMARY KEY, value TEXT NOT NULL)`，存 `current_source`
- `practice_archive(day TEXT NOT NULL, sentence TEXT NOT NULL, rounds INTEGER NOT NULL)`，存已删除素材每天练过哪句、几轮

### 素材状态

`sources.status` 增加 `probing`（查标题和时长）。完整流程：

pending → probing → downloading → transcribing → segmenting → ready / failed

### 打卡统计

`progress._practised` = 现有练习记录 + `practice_archive`。同一天同一句只算一句，轮数相加。

## 导入

- `ingest.pipeline` 拆成两步：
  - `begin_import(url, conn) -> source_id`：校验链接格式，建记录（标题先填链接，时长填 0，状态 pending）
  - `run_import(source_id, conn)`：查信息（超过 60 分钟就标 failed 并说明原因）→ 下载 → 转写 → 对齐 → 切句 → ready。任何异常都标 failed，保留原始错误信息
  - `import_source(url, conn)` 把两步串起来，命令行照旧用它
- 网页 `POST /api/sources`：校验格式 → 有导入在跑就返回 409 → `begin_import` → 起后台线程跑 `run_import`（线程里自己开数据库连接）→ 返回 `{id}`
- `GET /api/sources` 返回全部素材的状态，素材库页面轮询它
- `POST /api/sources/{id}/retry`：只有 failed 能重试。用原链接新建一次导入，删掉失败的那条记录
- 同一时间只允许一个导入：看库里有没有处在中间状态的素材
- 服务启动时（应用启动钩子），把处在中间状态的素材标成 failed「导入被中断」。命令行启动时本来就有同样的清理

已知限制：导入跑在服务进程里。关终端或改代码触发自动重载，都会打断正在跑的导入，素材会标成「导入被中断」，点重试即可。

## 删除

`DELETE /api/sources/{id}`：

1. 素材处在中间状态：返回 409
2. 把这份素材有指标的练习记录，按天、按句汇总写进 `practice_archive`
3. 在一个事务里依次删：attempts → practice_runs → saved_phrases → segments → sources。如果 `current_source` 指向它，改成最近练过的另一份能练的素材，没有就清空
4. 事务提交后删文件：原音 `audio_path`、各片段的句子音频缓存 `{segment_id}-u*.wav`、每遍录音 `attempts.audio_path`。文件删不掉只记日志，不回滚数据库
5. 返回 `{next}`：`/sources/{id}` 或 `/sources`

## 按素材分开

- `_sentences(connection, source_id)` 只列这份素材的句子，序号从 1 开始
- `_place` 在所属素材内找上一句、下一句和总数
- 列表页的「练过几次」「问题没解决」「盲听评分」只统计这份素材的片段上的练习记录，免得两份素材里文字相同的句子串在一起

## 错误处理

- 链接不是 http/https：400，页面在输入框下显示原因
- 已有导入在跑：409「上一份还在导入」
- 导入失败：卡片显示原始错误（比如 yt-dlp 的输出），不包装成笼统的「导入失败」
- 删除正在导入的素材：409
- 素材不存在：404

## 测试

- db：`practice_archive` 读写；删除素材后各表没有残留；`current_source` 跟着更新
- progress：删除前后打卡格子、连续天数、最近七天的数字完全一致
- pipeline：状态按顺序推进；超过时长上限标 failed 并带原因；出异常标 failed 并带原始信息（下载、转写打桩，不联网）
- web：`/` 的跳转规则；两份素材的句子编号、翻页、「开始下一句」互不串；素材库卡片的各种状态；导入接口的 400 / 409 / 成功；删除接口的 409 / 成功且清掉磁盘文件；启动清理；顶栏入口和练习页素材名链接存在
