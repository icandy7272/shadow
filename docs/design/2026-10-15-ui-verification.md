# 全页面 UI 重构验收 · 2026-10-15

范围：今天、日课与说明、练习入口、素材列表与详情、生词、记录列表／按天／逐轮详情、跟读、整段跟读、复述／自由说、设置、账号与设备、登录、缺失与不可练状态。保持所有原有模板 ID 与 data 属性、录音与加练逻辑、快捷键和认证接口。

## 已落实

- 固定顶层导航与内容归属；所有详情统一返回入口和主要标题，移除重复品牌导航。
- 合并共享层中重复的主要外壳、练习步骤和浮层规则；语义字号采用 rem，明暗主题、可读对比度及按下反馈统一。
- 素材、生词、记录、设置和口语列表明确文字区域与操作区域；搜索采用 SVG 图标、提示、清除和结果状态。
- 浮层替换时只保留一个可见层，继承原页面焦点，保留录音锁定保护和系统返回处理。
- 底部练习控制自测高度并为正文预留空间；空的导航槽不占位；自评分项文字提升可读性。
- 分区切换保留页面、搜索、筛选与滚动状态，浏览器恢复缓存页面时重新读取目标分区。录音草稿仍由原有 IndexedDB 会话负责。
- 设置新增标准、125%、150%、200% 文字大小，启动即恢复偏好，异常存储回退标准值。

## 浏览器验证

隔离练习数据；未使用或修改用户正式练习数据。

- 390×844：16 类页面逐页检查，无整页横向溢出；另打开真实记录详情入口检查返回层级。
- 320、430 和 844（横屏）宽度：今天、素材、素材详情、生词、记录、说明、设置、口语、练习共九类页面无整页横向溢出。
- 200% 字号：根字号32px；390宽九类页面和320宽五类页面无整页横向溢出。长标题、长英文单词有实际测试内容。
- 明暗主题实际切换；搜索→切换分区→回素材恢复查询。
- 素材操作→删除确认→取消：一个打开的 dialog，取消后焦点返回素材操作按钮，未执行删除。
- 练习操作→录音设置：一个打开的 dialog，关闭后焦点回到原页面；盲听自评后正确恢复／解锁既有步骤，未调用真实麦克风。
- 浏览器检查无控制台错误。新增结构与导航回归测试，完整 Python／Node 结果以提交时运行输出为准。

## 独立审查

设计符合性和代码质量审查均通过。审查发现并修复：替换浮层丢失原按钮焦点、说明页字号选择器不匹配、浏览器 BFCache 恢复后 tab 地址过期。

## 验证边界

桌面浏览器中的移动尺寸验证不等于真实 iPhone。主屏幕 App 的系统工具栏、软键盘、安全区、真实麦克风与 Face ID、VoiceOver 需要在实际设备上复核；本次没有更改线上 nginx 或初始化正式登录凭据。

## 练习底栏修正

根据 iPhone 截图追查到键盘高度计算将负视口偏移当作键盘的问题。修正为仅在文字编辑、正常缩放且视口缩短超过阈值时抬升底栏，忽略负偏移；根滚动区禁用纵向回弹。保存后底栏保留下一句主操作、加录次操作；新一轮与熟练标记移入菜单，保留原 ID、事件和快捷键。正文末尾去掉重复操作，空间按底栏实测高度预留。

使用隔离的三遍分析草稿走真实恢复流程验证：320/390宽无整页溢出，底栏只有加录按钮及下一句链接，原开始与熟练控件位于练习菜单；回到顶部后 CSS bottom 为0。键盘负偏移、非编辑滚动和缩放有回归测试。独立代码审查通过；真实 iPhone 原生回弹仍需设备确认。

## 按钮层级与录制状态统一

底栏统一角色样式与 DOM 顺序：次操作在左，主操作在右；单操作铺满。主操作实色强调、次操作卡片底与边框、停止实色红色，只有真实 disabled/inert 才弱化。新增真实录音状态标记，预听、录制、分析、待重试和已保存分别决定可见操作，录制时不显示开始或下一句。

隔离浏览器场景（模拟运行状态，未调用真实麦克风）验证：默写左跳过右对答案；反馈后开始跟读为100%不透明实色蓝；录制只显示左重来右说完了，预听／分析没有操作按钮，重试只有实色重新提交，保存后左加录右下一句。实际显示颜色、不透明度、位置与状态已检查。角色与运行状态优先级有回归测试，独立代码审查通过。
