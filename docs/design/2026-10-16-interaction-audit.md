# 练习交互复查与修复 · 2026-10-16

## 复盘

先前重构保留了多个入口：步骤标签、底栏代理按钮、原按钮、快捷键和恢复事件。验证偏重页面状态及单个函数，缺少跨入口的连续操作检查。测试数量不能证明这些入口行为一致；此前对快捷键完整性的表述超出了验证范围。

## 本轮确认与修复

1. “开始跟读”没有专门快捷键，文字箭头又会与下一句方向键混淆。改为 Enter 键帽及 aria-keyshortcuts；仅完成默写、未在输入框编辑且未按住重复触发时响应。右方向键仍只用于下一句。
2. 判分隐藏输入区域后，焦点可能留在不可见输入框中。电脑将焦点移到可见的继续按钮；手机移除输入焦点。
3. 方向键跳句绕过鼠标点击的保存链。改用同一链接点击入口，统一保存、导航保护和恢复处理。
4. 交互控件已经处理的按键仍会冒泡到全局快捷键；按住某些按键可能重复触发。全局处理忽略 defaultPrevented 和 repeat，保留控件自身的行为。

## 验证

- 对 Enter 的未完成、其他步骤、输入中、按键重复、事件已处理等条件执行回归。
- 验证方向键调用链接而不是直接改变地址。
- 隔离浏览器实际完成：输入默写 → Enter 判分 → 焦点转移 → 再次 Enter 进入同一句跟读 → 右方向键跳下一句并保留上一句草稿。
- “开始跟读”显示 Enter，未再显示装饰方向箭头。
- 未采集真实麦克风；不将本轮检查称为所有设备、所有交互已无问题。

## 后续改动的验收规则

按“状态 × 入口”验证：盲听、默写编辑、判分后、预听、录制、提交、保存、失败恢复；覆盖点击、键盘、自动推进及页面恢复。检查动作、焦点、声音、持久化和提示，避免只检查按钮是否出现。只报告实际完成的验证，不将单元测试通过等同于完整产品验收。
