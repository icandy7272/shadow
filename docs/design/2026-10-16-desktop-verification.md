# 宽屏布局验证 · 2026-10-16

## 范围

共享导航、今日、日课、练习入口、跟读工作区、记录、素材、生词、素材句子目录、口语练习、设置、账号、登录及原生 dialog。仅修改布局与必要模板容器，不改变录音和分析算法。

## 结果

- Python：595 项通过；JavaScript：107 项通过。
- 浏览器验证 320、390、1024、1100、1440、1920 CSS px，核心页面无横向溢出；1100px 起侧栏导航，以下保留触屏布局。
- 390 与 1440px 验证素材目录、日课说明、设置、口语练习、账号、登录，无横向溢出。
- 1440px、200% 应用字号验证首页、素材、练习。修正侧栏品牌文字溢出、两位数步进输入宽度；恢复标准字号。
- 使用隔离数据恢复保存结果，1100、1440、1920px 下底栏左右边界与活动练习面板一致。
- 模拟录制状态仅显示“这遍重来／说完了”；点击侧栏保持当前页并提示先结束录音。
- 从练习侧栏打开操作 dialog，540px 宽且在窗口居中；手机仍沿用原有浮层规则。
- 独立代码复核未发现交互结构回归。原有 ID、快捷键及会话控制器保留，练习侧栏不含答案。

## 验证边界

浏览器使用本机隔离测试数据，录制状态使用测试夹具，没有采集真实麦克风。本轮验证响应式布局，不能替代真实 iPhone Safari、主屏幕 App 或 VoiceOver 的设备验收。服务器认证逻辑未改变。
